# Satellite Pulse 1.0.1

## Mapas sin API key

- Eliminado CARTO de Satellite Pulse.
- OSM, Claro y Oscuro pasan a OpenFreeMap con datos de OpenStreetMap.
- Integración vectorial mediante MapLibre GL + MapLibre GL Leaflet.
- El botón **Aa** oculta solo los textos (`text-field`): conserva bosques, carreteras, agua, edificios e iconos.
- Satélite continúa con Esri World Imagery y su capa de nombres independiente.
- Actualizada la caché PWA a `satellite-pulse-v1.0.1`.
