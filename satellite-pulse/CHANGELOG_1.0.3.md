# Satellite Pulse 1.0.3

## Idioma del mapa
- OSM, Claro y Oscuro usan preferentemente `name:es` de OpenStreetMap.
- Cuando no existe traducción española, se conserva el nombre local/original.
- Satélite usa Esri World Imagery como imagen y OpenFreeMap/OpenStreetMap como capa de etiquetas, también localizada a español.

## Control de textos
- El botón **Aa** solo aparece con el mapa **Satélite**.
- En OSM, Claro y Oscuro los textos permanecen siempre visibles.
- En Satélite se puede activar o desactivar la capa de nombres.

## Radar
- Se conserva la corrección de v1.0.2: RainViewer se oculta automáticamente por encima de z=7.
